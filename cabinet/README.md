# 个人手办展柜

引入 `cabinet.css`，并使用 `import { mountCabinet } from './cabinet/cabinet.js'` 后调用 `mountCabinet(element)`。无运行时依赖。初始 4 个 POP MART 产品图来自官方产品页面，出处详见 `assets/sources.json` 和每件详情页，展示为「灵感样例」而非用户已拥有的收藏。

支持横向拖动、箭头键、上一件/下一件、详情、个人照片上传、添加与移除收藏。空间透视效果由照片卡片构成，并非手办实体的 360° 模型。上传的 JPG/PNG/WebP 限制 2 MB，最多 24 件，保存到当前来源的 localStorage，键为 `feiyang-cabinet-v1`。不会自动跨设备同步。

使用「导出收藏」下载包含照片的 JSON，使用「导入收藏」在其他设备恢复。导入采用合并方式：保留原收藏，跳过相同 ID，拒绝无效字段、重复 ID、错误的图片数据或超出上限的数据。文件上限为 8 MB；本地存储不足时显示错误，保持原收藏不变。上传对话框关闭后，未完成的读取不会继续保存；多点触控取消不触发翻页。

引用中的品牌及产品摄影版权属于原权利人。附带源码不宣称图片拥有独立授权；发布前可换成自己的手办实拍。
