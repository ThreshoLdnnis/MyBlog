# Mofarigano · Personal Journal

Mofarigano（朱飞阳 / Timofey / 老猪）的个人博客与生活收藏空间。把 Fashion Web 系列的巨型排版、纸张质感、立体陈列和人物造型切换，融入一本可翻页的生活手册；已有旅行地图、音乐墙与读书角作为独立页面接入。

本仓库包含当前静态网站的完整源码和运行素材。欢迎页、旅行地图、音乐墙、读书角、Orbit · 星际漫游和浪人X 的运行文件均随主站提供。

## 本地运行

安装 Node.js 后，可以双击 `启动网站.cmd`，或在本目录执行：

```powershell
npm run dev
```

打开 **http://127.0.0.1:4177/**。无需执行 `npm install`，主站没有构建步骤或 npm 依赖。按 `Ctrl+C` 停止服务。

主站使用 ES modules，请通过本地 HTTP 服务访问；不要直接双击 `index.html` 以 `file://` 方式打开。音乐光盘的 Three.js 与 GSAP 随站点提供，3D 唱片需要浏览器支持 WebGL。播放外部音源时仍需要网络。

请固定使用同一个浏览器、地址与端口。`localhost`、`127.0.0.1`、不同端口及未来部署域名的浏览器存储互不相通。

## 可以在这里做什么

顶部导航直接切换「我、奇点、生活、手记、足迹、音乐、阅读、收藏抽屉、荣誉墙」，右上角目录另提供「手办收藏、关于我、技术栈」的独立入口。每次只显示当前页面，不再把所有模块堆成长首页。页面只保留顶部导航，切换时以纸张透视翻页过渡，系统开启减少动态效果时立即切换。

每页拥有独立站内地址（例如 `#/works`、`#/music`），可刷新、收藏链接及前进后退；原有 `#works` 等旧链接仍可访问。音乐、地图、书架直接显示原互动页面，离开时会停止并卸载当前模块；已保存的数据保留。手机顶部采用两行导航，九项主栏目全部可见；也可从右上角目录选择任意页面。

| 模块 | 使用方式 |
| --- | --- |
| 开场与个人信息 | MovingSpider 互动欢迎页，点击 Welcome 下方「进入网站」后进入，不设倒数或自动跳过；页脚可重播；姓名大字支持鼠标或手指划过时粒子消散、离开后回聚；首屏显示本人照片，鼠标划过会沿轨迹撕开粉色骑手造型，约 1.1 秒后收拢；触屏支持滑动并保留轻柔自动演示，按钮可切换完整造型；目录中可编辑个人资料。 |
| 生活时间轴 | 按生活、学习、工作、创业筛选；在内容管理中新增、修改或移除记录。 |
| 奇点 | 按产品设计、视觉交互、策略模型筛选。点击音乐光盘、猪的读书角、Orbit · 星际漫游或浪人X 的封面可打开站内互动预览，关闭后回到原筛选位置。 |
| 旅行足迹 | 进入「猪的世界足迹」，探索世界地图、地点及代表性风景。未填写的日期和个人游记保留为空。 |
| 音乐墙 | 旋转与切换 3D 唱片、阅读歌词、编辑歌曲资料，并为歌曲添加自己的播放来源。 |
| 读书角 | 从立体书架抽取书籍，查看介绍、筛选分类、修改书单和阅读状态。初始书架为 51 本书、42 本已读。 |
| 手办展柜 | 拖动浏览、打开详情、上传自己的照片并添加收藏；支持单独备份。 |
| 收藏夹 | 收录工具、探店、地点、物品、语录与说说等内容，按类别筛选及标记喜欢。 |
| 技术栈与荣誉墙 | 展示技术方向；荣誉区从空白开始，可添加真实证书、奖项和记录。 |
| 博客手记 | 阅读、添加与编辑文章。两篇初始站点手记是本次制作撰写的开场内容，可改成自己的文字。 |

手办默认展示的 POP MART 产品图属于**灵感样例**，不代表本人已经拥有。展柜的立体感来自图片透视、层次和倾斜，不是可查看任意角度的真实 360° 三维模型。可以用自己的实拍替换样例；图片来源在每件详情与 `cabinet/assets/sources.json` 中记录。

荣誉区没有预填未经提供的奖项。音乐墙预置封面与歌曲资料，但**没有预置音频**；需在「收藏一首」或「编辑收藏」中添加自己的音频文件或可播放链接。音乐平台分享链接会打开平台页面，不能直接作为音频播放。

欢迎页复用 [MovingSpider](https://github.com/ThreshoLdnnis/MovingSpider) 的蓝色织物、收藏物件、跳蛛与蛛丝场景，并保留三主题切换。欢迎页独立运行，进入后卸载其动画；每次刷新仍需手动点击进入，站内切换页面不会重复出现。入口支持键盘操作，减少动态效果模式也保留进入按钮。来源与素材说明见 `welcome/README.md`。

## 编辑、保存与备份

页面中的「内容管理」是当前浏览器的内容编辑器，不是带身份认证的管理后台。主站使用 `localStorage`，地图、音乐、读书角及手办各自保持原有或独立的数据结构；主站导出文件不会自动包含其他模块的数据。

| 内容 | 保存与迁移方式 |
| --- | --- |
| 主站个人资料、时间轴、文章、收藏、荣誉 | 在「内容管理」使用「导出内容备份 / 导入内容备份」。数据键为 `feiyang-journal-v1`。导入会替换当前主站内容，并自动下载导入前内容的独立备份；迁移前仍建议先导出一份。 |
| 收藏夹的喜欢标记 | 单独保存在 `feiyang-journal-v1-saved`，不包含在主站内容导出中。 |
| 已移除的主站记录 | 进入回收记录，可在内容管理中「恢复上次移除的内容」。 |
| 读书角 | 在「编辑书架」中使用「导出书单 / 导入书单」，数据键为 `laozhu-reading-corner-v1`。 |
| 手办展柜 | 使用「导出收藏 / 导入收藏」，数据键为 `feiyang-cabinet-v1`。只导出个人收藏；导入合并记录并跳过相同 ID，原收藏保留。 |
| 音乐墙 | 歌曲资料、封面与音频保存在 `personal-music-corner` IndexedDB 中。支持导入歌词与音频文件，当前没有整库导出 / 导入入口，请保留原始封面、歌词和音频。 |
| 旅行地图 | 当前足迹为 HTML 中的内嵌数据，没有浏览器编辑器或导入 / 导出按钮。修改原项目 `work/travel/places.json` 并运行其 `assemble.cjs` 后，再更新主站的 `modules/map.html`。 |

浏览器内的编辑不会写回 `content.js`、原模块 HTML 或 GitHub。清除站点数据、换浏览器或换设备都会影响本地内容；迁移主站、书架与手办时，请分别备份。音乐收藏需要自行保留原始媒体。

要把内容设置为所有访客都能看到的默认版本，应修改对应源码或模块默认数据，再重新部署。主站的默认文案与作品列表集中在 `content.js`；现有浏览器存储优先于默认内容，已保存的个人修改不会因改动默认文件而自动消失。

## 源码分工

| 文件 | 职责 |
| --- | --- |
| `index.html` | 各独立页面、目录、导航与对话框结构。 |
| `styles.css` | 纸张配色、巨型排版、响应式布局与动效。 |
| `app.js` | 页面交互、筛选、文章详情、内容编辑、本地保存及模块入口。 |
| `page-navigation.js` | 站内路由、浏览历史、纸张翻页切换、模块按需加载与离页清理。 |
| `page-navigation.css` | 常驻导航、独立页面布局、桌面与手机翻页动效。 |
| `navigation-polish.css` | 九项中英双层主导航、响应式品牌排版。 |
| `typography.css` / `room-typography.css` | 主站排版层次，以及音乐、阅读中文标题的轻量字体适配。 |
| `name-particles.js` / `name-particles.css` | 姓名大字的局部粒子消散与回聚；保留可访问文字、触摸和减少动态效果适配。 |
| `portrait-reveal.js` | 沿用 Fashion Web5 的 Canvas 轨迹蒙版：不规则笔触、渐缩恢复、触摸与键盘替代操作。 |
| `content.js` | 个人资料、时间轴、收藏、文章、荣誉及作品的初始内容。 |
| `server.mjs` | 本地静态文件服务器，默认监听 `127.0.0.1:4177`。不处理账户、数据库或云同步。 |
| `cabinet/` | 独立手办展柜、样例图片、出处与使用说明。 |
| `modules/map.html` | 已有旅行地图的集成副本。 |
| `modules/music.html` | Music of Love 音乐墙的集成副本。 |
| `modules/books.html` | ReadingCorner 读书角的集成副本。 |
| `assets/` | 本人照片、作品封面、字体与预览图；`sources.json` 记录素材来源。 |
| `assets/fonts/` | 自托管字库、Unicode 分片、来源与 SIL Open Font License。 |

`npm run check` 可执行主站 JavaScript 文件的语法检查；这条命令不等同于浏览器交互或视觉测试。

## 字体与导航设计

导航以中文栏目名称为主、英文索引为辅，荣誉墙在桌面和手机顶部均直接可见。姓名大字保留 Anton；正文和控件使用 Instrument Sans 配合系统中文无衬线；中文标题与文章使用 Noto Serif SC 的本地派生字库；英文斜体使用 Instrument Serif；签名和少量题注使用 Caveat。字体详细来源与许可见 `assets/fonts/README.md`。

中文分为当前内容核心片和常用汉字补充片，按需加载；少见字保留系统字体回退。音乐与阅读保留原有英文字体、封面和排版尺寸，进入站内页面时仅轻量适配中文标题；地图保留原有霞鹜文楷。字体加载后会重算原模块布局。三个原始模块文件未修改。
